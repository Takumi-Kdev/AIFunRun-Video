# AIFunRun-Video Creative System

## 目的

このシステムは「動画ファイルを生成する機械」ではない。人間が一文で伝えた意図を、
視聴者に届く構成と一貫した演出を持つ作品へ変換する。人間が必ず行うのは外部公開の
最終承認だけで、制作条件の穴埋めはAIが担当する。

## 実装した創作ループ

1. **Intent** — 欲しい結果を自然言語で受け取る。
2. **Creative Direction** — 尺、配信先、視聴者、目的、フック、感情曲線を推定する。
3. **Visual / Audio Bible** — 色、光、構図、連続モチーフ、声、音楽、テンポを固定する。
4. **Shot Design** — 各ショットに役割、台詞、画面文字、画、カメラ、動き、転換を与える。
5. **Specialist Engines** — Blender/CAD/生成映像/TTS/FFmpeg/TK-CutExpressを必要に応じて使う。
6. **Composition** — ショット、字幕、声、BGMを一本のタイムラインへ統合する。
7. **Quality Direction** — 再生可能性、解像度、尺、音声を機械検査し、品質スコアを残す。
8. **Revision** — CreativePlanを保持したまま、自然言語の追加指示で再創作する。

## 人間の操作

最小操作は次の一回だけ。

```bash
python run.py create "欲しい動画"
```

DeepSeek APIがある場合は作品設計をLLMが行う。未設定・予算超過・通信障害でも、
決定的な自律ディレクターへ切り替わり、完成動画と品質報告まで生成する。

長尺横動画では `python run.py longform "テーマ" --minutes 10` を使う。DeepSeek は章構成・
台本・ショット設計に限定され、生成画像・生成動画・生成3D・音声クローンは呼び出さない。
ローカル素材と決定的な映像演出を組み合わせ、チャプターと途中再開状態を作品へ保存する。

## 品質の意味

`quality_report.json` の100点は技術的納品条件を表す。映像ストリーム45点、音声20点、
指定解像度20点、指定尺15点。投稿成果の良否は公開後の保持率・クリック・コンバージョンを
取り込み、将来のCreativePlan選択へ戻す。公開は常にAIFunRun側の承認ゲートを通す。
